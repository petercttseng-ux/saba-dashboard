所有靜態數值均可回溯至上列原始文件。臺灣民國114年數據另以年報 `.ods` 機讀原始檔逐項覆核，22 項關鍵數值全數吻合。

### 2025 年重點

- 花腹鯖產量 62,915 → **29,444 公噸（-53.2%）**，產值 -69.8%、單價 -35.6%，量價齊跌
- 扒網總漁獲 93,948 → 60,949 公噸（-35.1%）
- 衰退高度不對稱：基隆 -50.6%、宜蘭 -40.2%、新北僅 -9.2%
- 宜蘭「其他鯖科」（主為白腹鯖）378 → 3,795 公噸（+904%），出現魚種組成置換
- 2024 年扒網鯖鰺類 87,621 公噸已達 TAC 9 萬公噸的 97.4%；2025 年降至 50,167 公噸（55.7%）

## 漁場速預報：HSI 模型的文獻依據

環境適合度指數（HSI）之參數區間、因子選擇與合成方式均取自同儕審查文獻：

| 文獻 | 關鍵數值 | 採用方式 |
|---|---|---|
| Lu et al. (2021) *JMSE* 9:1341 | 東北部海域花腹鯖產卵期 1–5 月、盛期 2–4 月；東海成熟個體 SST 17–25 °C；2017 正常產卵年漁場日均溫 23–26.6 °C | 產卵期模式適溫區間（最適 19–24 °C、容忍 15–27 °C）與 1–5 月季節自動切換 |
| Kaneko et al. (2009) *J. Oceanogr.* 65 | 東海 7–9 月 >90% 漁獲之 Chl-a 0.15–0.50 mg/m³；四種 HSI 模型中 AMM 依 AIC 最佳 | Chl-a 最適下限 0.15 mg/m³；新增 AMM 合成模型選項 |
| Yu et al. (2018) *Fish. Res.* 207 | HSI 與 SSTA 正相關、與 SSHA 及 NPPA 負相關 | 佐證負 SSHA（冷渦、湧升）有利，現以溫度鋒面強度代理 |
| Frontiers Mar. Sci. (2025) | 氣旋渦內與渦緣漁獲密度高於反氣旋渦 | 列為後續強化方向（SSHA 圖層） |
| FRA (2025.11.11) 不漁要因第2報 | 黑潮續流極端北偏造成高溫、鯖魚難以南下 | 佐證水溫異常改變洄游路徑之機制 |

**三種合成模型可切換**：GMM 加權幾何平均（保守，任一因子偏低即拉低 HSI）／AMM 加權算術平均（Kaneko 2009 依 AIC 最佳）／MINM 最小值模式。

**季節情境自動切換**：1–5 月套用產卵期參數，6–12 月切換索餌期參數並提高鋒面權重。

> **模型限制**：文獻指出 SSHA／中尺度渦流與鹽度、混合層深度亦有顯著影響，但本儀表板目前僅取用 SST 與 Chl-a（加上由 SST 導出的鋒面強度）。因此本指數為**相對排序工具**而非絕對漁獲預測。

## 「最新資訊」自動更新功能

儀表板內建四路即時抓取，全部在瀏覽器端執行，不經任何後端伺服器：

1. **台灣鯖魚交易行情** — 農業部開放資料 API，近 30 交易日加權均價、成交量、市場別明細
2. **日本 FRA 資源評價** — 探測新年度評價頁面是否上線
3. **台灣漁業統計年報** — 探測新年度年報是否發布
4. **新聞・輿情** — 中日文鯖魚相關新聞標題

抓取結果存於瀏覽器 localStorage，下次開啟自動載入。

> **關於 CORS**：以 GitHub Pages（https）開啟時，跨網域限制較本機檔案（file://）寬鬆，但部分政府 API 仍未開放 CORS 標頭，因此程式內建「直連 → 公用代理」四段退避機制。代理僅轉發公開的政府開放資料與新聞 RSS，不傳送任何個人資訊。

## 授權與聲明

本儀表板為資源現況彙整與視覺化工具，數值以原始報告為準。FRA 與漁業署年報之核心數列（資源量、親魚量、F/Fmsy 等）採人工核校後寫入，不由程式自動改寫，以確保可回溯性。
