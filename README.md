# 鯖魚漁業資源儀表板｜台灣・日本

**農業部水產試驗所** ｜ Fisheries Research Institute, Ministry of Agriculture

整合台灣（花腹鯖・白腹鯖）與日本（マサバ太平洋系群・対馬暖流系群）鯖魚漁業資源現況的互動式儀表板。

## 內容

| 分頁 | 內容 |
|---|---|
| 總覽 | 三大族群資源狀態比較、神戶圖軌跡、漁獲量長期對比 |
| 最新資訊 | 一鍵抓取台灣魚市場即時鯖魚行情、FRA 新年度評價偵測、最新新聞 |
| 漁獲量趨勢 | 日本國別／漁業種別漁獲量、台灣鯖鰺漁業長期序列（1959–2024） |
| 資源動態 | 資源量、親魚量、加入量、RPS、F/Fmsy、%SPR、漁獲割合 |
| 體長・體重・年齡結構 | 年齡別漁獲組成、平均個體重、台灣體長變化 |
| 臺灣鯖魚專頁 | 2024 年魚種別／縣市別產量產值細部資料 |
| 管理與資源狀態 | 鯖鰺漁業管理辦法逐條整理、TAC 制度 |
| 資料來源 | 所有原始文件連結 |

## 資料來源

- 日本 水產研究・教育機構（FRA）令和 7（2025）年度資源評價報告
- 農業部漁業署《民國 113（2024）年漁業統計年報》
- 農業部農業資料開放平臺「漁產品交易行情」API（即時）
- Google News RSS（即時）

所有靜態數值均可回溯至上列原始文件。

## 「最新資訊」自動更新功能

儀表板內建四路即時抓取，全部在瀏覽器端執行，不經任何後端伺服器：

1. **台灣鯖魚交易行情** — 農業部開放資料 API，近 30 交易日加權均價、成交量、市場別明細
2. **日本 FRA 資源評價** — 探測新年度評價頁面是否上線
3. **台灣漁業統計年報** — 探測新年度年報是否發布
4. **新聞・輿情** — 中日文鯖魚相關新聞標題

抓取結果存於瀏覽器 localStorage，下次開啟自動載入。

> **關於 CORS**：以 GitHub Pages（https）開啟時，跨網域限制較本機檔案（file://）寬鬆，但部分政府 API 仍未開放 CORS 標頭，因此程式內建「直連 → 公用代理」四段退避機制。代理僅轉發公開的政府開放資料與新聞 RSS，不傳送任何個人資訊。

## 授權與聲明

本儀表板為資源現況彙整與視覺化工具，數值以原始報告為準。FRA 與漁業署年報之核心數列（資源量、親魚量、F/Fmsy 等）採人工核校後寫入，不由程式自動改寫，以確保可回溯性。
